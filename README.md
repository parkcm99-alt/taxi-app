## 왜 만드는가

**택시운전자격시험 합격**이 목적입니다. 기존 문제집·강의 자료가 종이와 음성으로만 흩어져 있어, 실제 시험과 같은 조건(70문항·70분·과목별 배분)으로 반복 연습할 수단이 없었습니다.

그래서 다음을 만족하는 도구를 직접 만듭니다.

- **실제 시험과 동일한 조건**으로 무제한 반복 응시 — 매번 랜덤 추출 + 선택지 셔플이라 답 위치를 외울 수 없음
- **틀린 문항만 다시** 풀 수 있는 오답노트
- **설치 없이 폰에서** 바로 — 단일 HTML + GitHub Pages, 오프라인에서도 동작
- **기록이 기기에 남음** — localStorage에 저장, JSON으로 백업·복원

이미 같은 방식으로 만든 [버스 앱 v7](https://parkcm99-alt.github.io/PRACTICE-TEST/)이 있고, 이 프로젝트는 그 택시 버전입니다.

## 시험 요강

| 항목 | 내용 |
|---|---|
| 문항 수 | 70문항 |
| 시간 | 70분 |
| 합격 | 42문항(60%) 이상 |
| 과목 | ① 법규 20 · ② 안전운행요령 20 · ③ 운송서비스 20 · ④ 서울지역 지리 10 |

### 경기지역 지리(4-2)를 제외한 이유

교재는 4과목 지리를 **4-1 서울 / 4-2 경기**로 나눠 싣고 있지만, 실제 응시에서는 **둘 중 한 지역만** 출제됩니다. 이 앱은 **서울지역 지리만** 다루므로, 교재의 경기 지역 문항은 수집 대상에서 제외합니다.

> 응시 지역이 바뀌면 이 결정도 함께 바꿔야 합니다. `images/*/`의 원본 사진에는 경기 문항도 찍혀 있으므로 추가 촬영 없이 확장할 수 있습니다.

## 구조

```
taxi-app/
├── index.html              ← 배포물. 단일 파일 (약 364KB, SVG·데이터 전부 인라인)
├── README.md               ← 이 문서
├── CODEX_지침서.md          ← 병렬 작업용 규격서
├── docs/                   ← 문제 원장(原帳). 마크다운이 유일한 진실
│   ├── 택시_기출_텍스트_Q001-Q070_승인본.md
│   ├── 택시_기출_텍스트_Q071-Q160.md
│   ├── 택시_기출_텍스트_Q161-Q240.md
│   └── 택시_CBT_제1~7회_70문항.md
├── source/                 ← STT 원문 · 강의 텍스트 (가공 전 원본)
├── images/                 ← 교재 사진 1~7회 (판독 근거)
└── tools/
    ├── parse.py            ← docs/*.md → questions.json
    ├── verify.py           ← 정답표 대조 검증
    └── app_template.html   ← 앱 뼈대 (__QUESTIONS__ 자리에 데이터 주입)
```

### 설계 원칙

**마크다운이 유일한 진실(single source of truth)입니다.**
`index.html`은 `docs/*.md`에서 자동 생성되는 산출물이므로, **문제를 고칠 때는 반드시 마크다운을 고치고 다시 빌드**합니다. HTML을 직접 수정하면 다음 빌드에서 사라집니다.

---

## 빌드

```bash
python3 tools/parse.py /tmp/questions.json
```
```bash
python3 - <<'EOF'
tpl = open("tools/app_template.html", encoding="utf-8").read()
data = open("/tmp/questions.json", encoding="utf-8").read()
open("index.html", "w", encoding="utf-8").write(tpl.replace("__QUESTIONS__", data))
print("index.html 생성 완료")
EOF
```

`parse.py`는 `오류 0`이어야 합니다. 오류가 있으면 해당 마크다운의 형식이 깨진 것입니다.

### 로컬에서 열어보기
`index.html`을 브라우저로 직접 열어도 동작하지만, 서버로 띄우면 실제 배포 환경과 같아집니다.
```bash
python3 tools/serve.py
```

## 앱 규격

| 항목 | 값 |
|---|---|
| localStorage 키 | `taxiExamStats_v1` — **버스 앱 `busExamStats_v3`와 반드시 분리** |
| 과목 배분 | `SUBJECT_QUOTA = { 1:20, 2:20, 3:20, 4:10 }` |
| 문항 데이터 | `{ id, subject, q, choices[4], answer, exp, img }` |
| answer | **0-based** (①=0) — 가장 실수가 잦은 부분 |
| ID 접두어 | `t-` 텍스트 기출 / `c1-`~`c7-` CBT 1~7회 |
